### Template-B Language for Task Descriptions

When creating the `description` field for the task, you **must** use the `Template-B` language to reference parameters from the input semantic call. This allows the final task description to be dynamic.

**Template-B Syntax:**

1.  **Variable Substitution**: Use `<%= variable_name %>` to insert a variable's value.
    *   Example: `Analyze the sentiment of this text: <%= user_comment %>`

2.  **Parameter Referencing**:
    *   **Positional Parameters**: Reference them by their 0-indexed position, like `<%= arg0 %>`, `<%= arg1 %>`, etc.
    *   **Keyword Parameters**: Reference them directly by name, like `<%= user_id %>`.
    *   **Field Access**: Use dot notation to access fields within a parameter object, like `<%= arg0.name %>` or `<%= user.address.city %>`.

3.  **Loops**: Use `<% collection.each do |item| %> ... <% end %>` to iterate over a collection.
    *   Example:
        ```
        <% users.each do |user| %>
        - Process user: <%= user.name %> (<%= user.id %>)
        <% end %>
        ```

4.  **Simplicity**: The template language only supports variable substitution and loops as described. Do not use or invent any other syntax.

**Quality Guidelines:**
*   **Title**: The `title` should be a concise, clear summary of the semantic call's intent.
*   **Description**: The `description` should be a well-structured, readable, and complete instruction set for a general AI agent. It should be written in natural language and use Template-B to elegantly integrate dynamic data.
